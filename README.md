# 🐾 ЗвероМир — Приют для животных

Платформа для поиска питомцев из приюта.

## 🚀 Запуск проекта

### Требования

- Node.js 18+
- npm или yarn

### Установка и запуск

```
# Клонировать репозиторий
git clone https://github.com/Torerroo/ZveroMir
cd ZveroMir

# Установить зависимости бэкенда
cd backend
npm install

# Установить зависимости фронтенда
cd ../frontend
npm install
```

## 🛠 Технологии

- **Бэкенд:** Express.js, Multer
- **Фронтенд:** Next.js, Tailwind, Three.js
- **База данных:** SQLite, PostgreSQL + Prisma
